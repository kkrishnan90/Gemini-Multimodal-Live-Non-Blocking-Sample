# Overview

We are developing a Gemini Live API based application for AI powered smart glasses. The base prompt is provided in @base_prompt.md file. 

## Goal

- To enhance the base prompt following the best practices of Gemini prompting guide
- The model to be used gemini-2.5-flash-native-audio
- There are sample functions and their requirements provided. All these functions are to be mocked with a response in our code
- Our enhanced system instructions/prompt will make sure that the Gemini Live API on Vertex AI will function with greatest/highest system instruction adherence 
- For agents related function/tool calls, create mock tool calls with expected responses
